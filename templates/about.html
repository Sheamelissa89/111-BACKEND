About the project

Financial organization made approachable.

Budget Manager is a full-stack web application designed to help users organize expenses and better understand where their money is going.

The purpose

Why I created Budget Manager

Managing financial information can become overwhelming when records are scattered or difficult to understand. I created Budget Manager to provide a clear, simple, and approachable system for reviewing expense information.

The application connects an original frontend design with a Flask backend and SQLite database. Each part of the project works together to create a complete user experience.

Project goal

Clarity creates confidence.

This project transforms stored financial data into information that users can understand and act upon.

Demonstrated competencies

How the application was built

01

Flask Routing

Python routes receive browser requests and return HTML pages or JSON responses.

02

Jinja Templates

Template inheritance creates a consistent layout while allowing each page to contain unique content.

03

SQLite Database

Expense records are retrieved, updated, and deleted through parameterized SQL commands.

04

Responsive Design

Custom HTML and CSS produce an accessible layout that adapts to different screen sizes.

HTML · CSS · Jinja · Flask · Python · SQL · SQLite
